# Modern Pluto Client

View and edit Pluto.jl notebooks directly in VS Code / Cursor.

## Features

- **View Pluto Notebooks**: Open `.jl` files created with Pluto.jl in a notebook-style interface
- **Edit Cells**: Modify cell content with automatic saving
- **Add/Delete Cells**: Create new cells or remove existing ones
- **Reorder Cells**: Move cells up and down
- **Toggle Visibility**: Control whether cell code is visible in Pluto view

## Usage

1. Open any `.jl` file that is a Pluto notebook
2. The file will automatically open in the Pluto Notebook Editor
3. Or right-click on a `.jl` file → "Open as Pluto Notebook"

## Requirements

- VS Code 1.108.0 or higher (or Cursor)

## Known Issues

- Code execution is not yet supported (viewing/editing only)
